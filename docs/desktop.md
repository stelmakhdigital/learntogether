# Десктоп

Приложение — окно Electron. Веб-интерфейс остаётся инструментом разработки
(Vite-прокси) и веб-сборкой для этапа 7, но основной продукт запускается окном.

## Что делает оболочка

`apps/desktop/main.mjs`:

1. генерирует одноразовый токен доступа и запускает сервер отдельным процессом
   (`packages/server/src/main.ts`), узлом которого по умолчанию служит сам Electron
   в режиме Node (`ELECTRON_RUN_AS_NODE=1`) — один рантайм, один бинарник
   `better-sqlite3`;
2. ждёт строку `сервер на http://127.0.0.1:PORT` и открывает окно на этом адресе;
3. передаёт токен во фрагменте адреса (`#token=`). Фрагмент не уходит на сервер,
   поэтому токен не попадает в строки запросов и логи прокси; интерфейсный код
   читает его из фрагмента и кладёт в заголовок `Authorization`;
4. не пускает в окно ничего чужого: переходы вне адреса приложения и новые окна
   уходят в системный браузер;
5. по закрытию окна шлёт серверу `SIGTERM` (тот закрывает базу), через 5 с —
   `SIGKILL`.

Ключ модели оболочка окну не отдаёт: он остаётся в окружении серверного процесса.
База — в каталоге данных (`LTH_DATA_DIR`, по умолчанию `~/.config/learntogether`),
оттуда же читаются настройки модели.

## Запуск из репозитория

```
pnpm build
pnpm --filter @learntogether/desktop start -- --no-sandbox
```

`--no-sandbox` нужен в дев-запуске: SUID-хелпер песочницы Chromium принадлежит root
(в собранном AppImage он свой).

```
pnpm desktop:smoke
```

поднимает оболочку на виртуальном X-сервере, подключается к окну по CDP, говорит,
что увидел, и пишет скриншот `/tmp/lth-desktop.png`. В `pnpm verify` этот прогон не
входит: он требует Electron.

headless ozone для этого прогона не используется: снятие окна в нём падает
(`GPU process isn't usable`), а скриншот настоящего окна — часть проверки.

## Что осталось этапу 8

Раскладка собранного приложения (сервер внутри пакета, рядом — собранный
интерфейс и ресурсы), сборка AppImage/NSIS/DMG, автообновления, иконки. Пока
оболочка запускает сервер из исходников репозитория — это помечено `shortcut:` в
`apps/desktop/main.mjs`.
